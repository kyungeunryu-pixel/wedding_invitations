모바일 청첩장 파일 안내

1. index.html을 브라우저에서 열어 미리 볼 수 있습니다.
2. 사진을 넣으려면 index.html과 같은 위치에 images 폴더를 만들고 아래 파일명을 사용하세요.
   - cover.jpg : 첫 화면 커플 사진
   - groom.jpg : 신랑 소개 사진
   - bride.jpg : 신부 소개 사진
   - gallery-01.jpg ~ gallery-06.jpg : 갤러리 사진
3. 계좌번호는 index.html에서 '신랑측 계좌번호 1' 등의 예시 문구를 실제 은행/계좌번호/예금주로 교체해야 합니다.
4. 신랑·신부의 MBTI, 사는 곳, 직업, 취미와 문답도 index.html에서 '추후 입력' 문구를 찾아 바꾸면 됩니다.
5. 예식장 주소, 대중교통, 주차 정보는 정확한 공식 안내를 확인한 뒤 입력하세요. 지도 버튼은 네이버 지도/카카오맵/구글 지도 검색으로 연결됩니다.
6. 현재 페이지에는 예시용 정보가 포함되어 있으므로 공개하기 전에 반드시 확인해 주세요.
